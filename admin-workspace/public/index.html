System Architecture & Security Guardrails

Separate Codebase:

This Admin Workspace is decoupled from the Android client app and deployed independently.

Privileged Service Layer:

Uses Firebase Admin SDK and server-side Cloud Functions. No service account keys in client code.

Firestore Security Rules:

Client writes to financial ledgers, match results, and wallets are strictly blocked at database rule level.

Explicit Admin Allowlist:

Admin privileges granted only through Firebase Custom Claims or protected admin_users collection.
