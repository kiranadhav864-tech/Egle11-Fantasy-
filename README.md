# Egle11 🦅

Egle11 is a skill-based fantasy cricket gaming app.

## Features

- Mobile number registration
- OTP verification
- User profile
- Cricket matches
- Create and manage fantasy teams
- Join contests
- My Matches
- Winners
- Recommended Matches
- Wallet
- Add balance using PhonePe / Paytm
- Notifications
- Firebase backend and database
- Admin panel for managing matches, players and contests

## Technology

- Flutter
- Dart
- Firebase
- Cricket API

## Project Structure

lib/
  main.dart
  screens/
  widgets/
  services/
  models/

## Setup

Run:

flutter pub get

Then:

flutter run
